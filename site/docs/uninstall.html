Uninstalling SakuraOS

How to remove SakuraOS depends on whether it has a disk to itself or shares one with Windows. Either way, back up anything you want to keep from SakuraOS first: removing it deletes everything on its partition, including your home folder.

SakuraOS on its own disk

Install the other operating system and let its installer erase that disk. Nothing else is needed. If the computer's boot menu still lists SakuraOS afterwards, delete that entry in the firmware settings.

SakuraOS beside Windows

Do these steps in Windows, in this order. Fixing the startup files first means the computer never tries to start a SakuraOS that is no longer there.

1. Put Windows' startup files back

Open Command Prompt as administrator: search the Start menu for cmd, right-click Command Prompt and choose Run as administrator. Use Command Prompt, not PowerShell or Terminal, as these commands are written for it. Run them one at a time. If S: is already in use, pick another free letter and use it everywhere below. 

mountvol S: /S
rmdir /S /Q S:\EFI\sakura
bcdboot C:\Windows /s S: /f UEFI
mountvol S: /D

The first line gives the EFI system partition a drive letter, the second removes SakuraOS's startup files, the third rewrites Windows' own, and the last removes the drive letter again.

2. Remove the SakuraOS startup entry

In the same window:

bcdedit /enum firmware

Find the entry whose description is SakuraOS and note its identifier, which looks like {12345678-abcd-…}. Then run the following, replacing the text in quotes with that identifier, braces included: 

bcdedit /delete "{identifier}"

3. Delete the SakuraOS partition

  1. Right-click the Start button and choose Disk Management.

  2. Find the SakuraOS partition. It has no drive letter, is the size you gave SakuraOS, and usually sits right after the (C:) partition. If you are not sure which it is, stop and ask: deleting the wrong partition loses its files.

  3. Right-click it and choose Delete Volume.

  4. To give the space back to Windows, right-click (C:) and choose Extend Volume. This only works if the free space is directly after C:.

Restart. The computer now starts straight into Windows.
