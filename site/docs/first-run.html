After installing

Most of the setup a new Arch install usually needs is already done. This page is what was done, so you are not looking for it, and the short list of things actually worth doing yourself.

Already done

You do not need to enable, configure or install any of this:

  • Automatic updates, at 03:00, on mains power, after a restore point, and never with an unattended reboot.
  • Restore points, taken before every package transaction, with the boot-time recovery environment that reads them.
  • The firewall and network: NetworkManager is running and bluetooth is enabled with it.
  • Printing, socket-activated, so it costs nothing until you print.
  • Compressed swap in RAM, the I/O scheduler rules and the sysctl values described in Tuning.
  • Flatpak and Snap, both configured, so the App Store's four sources all work immediately.
  • Your browser, the one you chose during the install, pinned to the panel.

Worth doing

Run the first update yourself

The image was built at some point before you downloaded it. Open the Update Center and install what is pending rather than waiting for 03:00, so you start current. A restore point is taken first, as always.

Decide about the AUR

It is off. If you want it, turn it on in Settings and read The AUR first, particularly the part about what the review screen is showing you. If you do not need it, leaving it off is a real security decision rather than a default nobody thought about.

Check the restore points exist

Open the Update Center, History. There should be one from the installation itself. It costs ten seconds and it tells you the safety net is real on your machine specifically, rather than in principle.

Set up your backups

Restore points are not backups. They live on the same disk and they protect you from a bad update, not from a failed drive or a stolen laptop. Anything you would be upset to lose needs a copy somewhere else.

This is the one thing on this page that SakuraOS cannot do for you, and the one most likely to matter.

If you use Secure Boot

Check whether it was enrolled: if your firmware was not in setup mode during the install, the installer completed with Secure Boot off and said so. See Hardware.

Making it yours

The accent colour, clock format, wallpaper and theme you chose during installation are ordinary Plasma settings, and changing them later is done in System Settings like anything else. Nothing about them is locked.

Sakura Settings holds the parts that are ours: the AUR switch, what Terminal Assist does, when updates install, and whether Windows application support is set up at all.

If something is already wrong

Go to Troubleshooting. If the machine will not start, Recovery covers it and you do not need anything else.
