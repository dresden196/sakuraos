The App Store

The App Store finds, installs, updates and removes applications. It searches several sources at once, and when an application is available from more than one, it lets you choose.

Finding and installing an application

  1. Search at the top, or browse by category on the left.

  2. Open the application's page for its description, screenshots, reviews and license.

  3. Under Install from, check which source is selected. The store picks one for you; see below.

  4. Press Install, and type your password if asked.

You can start several installs without waiting. Installs from the same kind of source take turns; different kinds, such as a Flatpak and a SakuraOS package, run at the same time. The store shows each one as waiting, installing or failed.

Where applications come from

SourceWhat it is
SakuraOSPackages from Arch Linux and SakuraOS. The smallest downloads, updated with the rest of the system.
FlatpakApplications from Flathub. Each runs in a sandbox with its own copy of what it needs, so downloads are larger. Often the newest version. The page lists what each one is allowed to access.
SnapApplications from Canonical's Snap Store. Some software is only published here.
AppImageA single file you download from a website. See AppImages.
AURBuild scripts written by Arch users, which nobody reviews. Off until you turn it on. See The AUR.

When an application is available from more than one source, the store selects the one you already have installed. If you have none, it selects SakuraOS first, then Flatpak, Snap, AppImage and the AUR. To use a different one, click it before pressing Install.

Updates

Everything is updated automatically: SakuraOS packages with the nightly system update, and Flatpaks, Snaps and AppImages by the store shortly afterwards. Applications from the AUR are the exception; see updating AUR packages.

Removing an application

Open Installed, choose the application, and press Uninstall. Tick Also remove its settings and saved data to remove what it stored in your home folder as well.

The store will not remove something the system needs to start or to update itself. See Terminal Assist.

AppImages

An AppImage is a whole application in one file, downloaded from the developer's website. Open the downloaded file and the store offers to install it: the file is copied to the Applications folder in your home folder and added to the application menu.

An AppImage is only as trustworthy as the website you downloaded it from, and the store says so before installing. Many AppImages cannot update themselves; the store tells you when that is the case.

Reviews

Ratings and reviews come from the Open Desktop Ratings Service, which GNOME Software and KDE Discover also use. To write one, open an application you have installed and choose Write a review. Reviews are public, under whatever name you choose.

App Sync

To set up a new computer with the same applications, click your name at the bottom left of the store and choose Save this machine's list…. On the new computer, choose Open a list… and pick that file. The list holds only application names: no settings and no files.

What the store does not show

The store lists applications that appear in the application menu. Command-line tools and libraries are not listed. Install those in a terminal with sudo pacman -S name.
