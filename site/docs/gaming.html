Gaming on SakuraOS

Nothing here is SakuraOS-specific magic. It is Arch with a current kernel, current Mesa and a scheduler tuned for a desktop, which is most of what gaming on Linux needs. This page is the setup and the things worth checking when a game misbehaves.

Steam

Install Steam from the App Store. The repository version is the one to take: it is the native package, it updates with everything else, and it uses your system's graphics drivers rather than carrying its own.

In Steam, turn on Steam Play for all titles under Settings, Compatibility. That is what runs Windows games through Proton, and it is off by default in Steam itself rather than by anything we did.

Proton

Proton is Valve's Wine, maintained for games specifically. It is a better choice for games than the general Wine that Windows applications describes, and the two do not conflict.

When a game does not run on the default Proton, the usual answer is a different version rather than a fix: right-click the game, Properties, Compatibility, and force a specific one. Older titles frequently want an older Proton. ProtonDB is where people record which one worked.

Launch options worth trying

Set these per game in Properties, General, Launch Options. Each solves a specific class of problem rather than being a general improvement:

  • gamemoderun %command% asks the system to prioritise the game while it runs.
  • PROTON_LOG=1 %command% writes a log to your home directory, which is what to attach when asking why a game will not start.
  • -vulkan or -dx11 depending on the title, when the default renderer misbehaves.
  • gamescope -- %command% for games that handle resolution or focus badly on Wayland.

Controllers

Xbox and PlayStation controllers work over USB and bluetooth without setup. Steam Input handles the mapping, including for non-Steam games added to the library. A controller that pairs but does nothing is usually one Steam has not been told to support: Settings, Controller, and enable the layout for its type.

Other launchers

Lutris and Heroic are both in the App Store and cover GOG, Epic and games outside Steam. They use the same Wine and Proton builds underneath, so nothing about the driver setup changes.

Graphics drivers

Nothing to install: whatever your card needs was installed during the install, and it is the same driver everything else on the desktop uses. If performance is poor on an older NVIDIA card, check which driver you are on first, because Nouveau and the frozen 580xx branch behave very differently from the current one. See Hardware.

When a game will not start

In order, because each rules out the one below it:

  • Try a different Proton version. This is the answer more often than everything else combined.
  • Check ProtonDB for the title. Someone has usually hit it already.
  • Run with PROTON_LOG=1 and read the end of the log in your home directory.
  • Verify the game's files from Steam, which catches a genuinely broken download.
  • Check whether it broke after a system update, from the Update Center history. If it did, a restore point is faster than debugging it, and worth doing before you spend an evening on it.

Anti-cheat

Some multiplayer games do not run on Linux at all, because their anti-cheat refuses to. This is a decision by the game's publisher and no distribution can work around it. Are We Anti-Cheat Yet? tracks which titles those are. If a game you want is on that list, no amount of configuration here will change it.
