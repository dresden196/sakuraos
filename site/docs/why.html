Why SakuraOS

SakuraOS is based on Arch Linux. You get Arch's up-to-date software, with the setup already done and a way to undo changes that go wrong.

What it is

SakuraOS installs Arch Linux's own packages, straight from Arch's servers, unchanged. On top of them it adds a few pieces of its own: a graphical installer, restore points you can go back to from the boot menu, automatic updates, an App Store, and a tuned kernel. These come from SakuraOS's own package repository.

It is a rolling release. There are no big version upgrades every six months or two years. Your system updates a little at a time, and you always have the current release of every program.

Who it is for

  • People who want current software and a modern desktop without assembling the system themselves.
  • People coming from Windows or macOS who would rather not use a terminal for everyday tasks.
  • Arch users who want restore points and recovery set up for them.

Who it may not suit

  • If you want to choose every part yourself, plain Arch Linux is the better starting point. SakuraOS makes those choices for you: the desktop is KDE Plasma, the file system is BTRFS, and the boot loader is Limine.
  • If you need software that changes rarely, such as for a server or a managed office computer, a distribution with long-term support releases will suit you better than a rolling release.
  • If your computer is not a 64-bit PC with UEFI firmware, SakuraOS will not install. See System requirements.

SakuraOS and the Arch community

Because SakuraOS uses Arch's packages, most of the Arch Wiki applies to it and is an excellent reference. Some things are different, though: the boot loader, restore points and updates work the SakuraOS way, described in this wiki.

SakuraOS is not affiliated with the Arch Linux project. If you have a problem, ask in the SakuraOS community first rather than in Arch's forums, since the cause may be something SakuraOS does differently.
