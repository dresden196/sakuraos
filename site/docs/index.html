SakuraOS wiki

SakuraOS is a Linux distribution based on Arch Linux, with the KDE Plasma desktop. It installs in a few screens, keeps itself up to date, and takes a restore point before every update, so an update that goes wrong can be undone from the boot menu.

About this wiki

Every page is checked against the SakuraOS release named at the bottom of it. If something here does not match what your computer does, the page is wrong, and a report is welcome. The wiki lives in the SakuraOS repository, so corrections can also be sent as a pull request.
