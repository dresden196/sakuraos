What SakuraOS is

Arch underneath, KDE Plasma on top, BTRFS with automatic restore points, and a boot chain built out of limine and unified kernel images. Every one of those is a choice somebody normally has to make during an Arch install, and making them is most of what an opinionated distribution is for.

The parts that are ours are the ones that were missing: an installer that asks in plain language, a store that covers four packaging systems at once, an update engine that takes a restore point before it touches anything, and a guard that sits inside pacman rather than beside it.

What it is not

It is not a locked-down system. Every guard here names its own override, the AUR is one checkbox away, and nothing stops you replacing any of it. The defaults are opinions, not restrictions.

It is also not finished. This documentation describes what is built and working today. Where something is planned rather than present, it says so rather than describing it in the present tense.

Getting help

Every page here is written from the code that ships. If something on this site does not match what your machine does, the machine is right and the page is a bug worth reporting.
