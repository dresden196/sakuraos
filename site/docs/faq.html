Frequently asked questions

Short answers, with links to the pages that go further.

About SakuraOS

What is SakuraOS?

A Linux distribution based on Arch Linux, with the KDE Plasma desktop. It adds a graphical installer, restore points, automatic updates, an App Store and a tuned kernel. See Why SakuraOS.

Is it a fork of Arch?

No. SakuraOS installs Arch's own packages, unchanged, from Arch's servers. It adds its own applications and kernel from a separate SakuraOS repository.

Is it free?

Yes. It costs nothing, and everything SakuraOS makes is open source under the GPL-3.0. The source is on GitHub.

Do I need to know Linux?

No. Installing, updating, installing applications and going back after a problem all work without a terminal. If you do use one, Terminal Assist stops the commands known to break the system and explains why.

Can I use a different desktop than KDE Plasma?

SakuraOS is built around Plasma, and it is the only desktop it supports.

Installing

Will it run on my computer?

If it is a 64-bit PC with UEFI firmware, most likely. See System requirements.

How big is the download?

About 3.2 GB. There is one image for every computer.

Can I try it without installing?

Yes. Start from the USB stick and choose Try SakuraOS. Nothing on your computer changes, and nothing you do is kept.

Can I keep Windows?

Yes. See Dual boot with Windows.

Can I install without an internet connection?

Yes. Everything needed for a working desktop, including the Zen browser, is on the USB stick. Two things are downloaded only when connected: a browser other than Zen, and the driver for NVIDIA GTX 900 and 1000 series cards.

Is Secure Boot supported?

Yes, but it needs one extra step before installing. See Secure Boot.

Everyday use

Will an update break my computer?

It can happen on any system that updates. SakuraOS makes it rare and easy to undo: updates are tested on a SakuraOS machine first, updates that Arch says need a manual step are held back, and a restore point is taken before every change. See Updates.

What if my computer will not start?

After three failed starts in a row, the recovery screen opens by itself and lets you go back to a restore point. You can also choose SakuraOS Recovery in the boot menu at any time. See Going back.

Can I use the AUR?

Yes. It is off until you turn it on in SakuraOS settings. When you install from it in the App Store, you see the build script first. See The AUR.

Can I use yay or paru?

Yes. Choose one under Command-line helper in SakuraOS settings, and SakuraOS installs it for you.

Can I play games?

Yes, including most Windows games through Steam. See Gaming.

Can I run Windows programs?

Some. SakuraOS can install Wine, which runs many Windows programs, though not all of them. See Windows apps. Many popular Windows applications also have a web version that works in the browser.

Does SakuraOS collect data about me?

No. See Privacy.
