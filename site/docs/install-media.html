Making a USB and starting from it

Download SakuraOS, write it to a USB stick, and start your computer from the stick. Writing the image erases everything on the USB stick, so use one with nothing on it you need.

1. Download

Download the image from sakuraos.org. It is one file of about 3.2 GB, named sakura-latest-x86_64.iso. There is only one version; it works on every supported computer.

2. Check the download

This step is optional, but it confirms the file arrived complete and really came from SakuraOS. Download the checksum file from the same place: sakura-latest-x86_64.iso.sha256. It contains one long code. Then compute the code for your download and check that the two match.

On Windows, open PowerShell in your Downloads folder and run:

Get-FileHash sakura-latest-x86_64.iso -Algorithm SHA256

On macOS, open Terminal in your Downloads folder and run:

shasum -a 256 sakura-latest-x86_64.iso

On Linux, with both files in the same folder:

sha256sum -c sakura-latest-x86_64.iso.sha256

To also check that the image was made by SakuraOS, verify its signature. The commands and the signing key's fingerprint are on the download page.

3. Write it to a USB stick

You need a USB stick of 8 GB or more. Everything on it will be erased.

Your current systemUseNotes
WindowsRufusWhen Rufus asks how to write the image, choose Write in DD Image mode.
Windows or macOSbalenaEtcherChoose the file, choose the USB stick, and press Flash.
LinuxFubukiSakuraOS's own USB writer, available as an AppImage or a Flatpak.
LinuxddSee below.

With dd, first find the USB stick's name. Run lsblk before and after plugging it in; the new entry is the stick, for example /dev/sdb. Then run the command below with that name. 

sudo dd if=sakura-latest-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync

Check the device name twice. dd writes to whatever you name, without asking. Naming your system disk instead of the USB stick erases it.

4. Start the computer from the USB stick

  1. Plug the USB stick into the computer you want to install on. Use a port directly on the computer rather than a hub.

  2. Turn the computer on, or restart it, and immediately press its boot menu key a few times. Which key depends on the manufacturer:

    ManufacturerBoot menu key
    Acer, Dell, Gigabyte, LenovoF12
    ASRock, MSIF11
    ASUSF8 on desktops, Esc on laptops
    HPF9, or Esc then F9

    On many laptops you have to hold Fn as well, for example Fn+F12. Some Acer computers only show the menu after it is turned on in the firmware settings, and some Lenovo laptops have a small Novo button beside the power button instead. If none of these work, the key is usually shown briefly on screen as the computer starts, or listed in its manual.

    From Windows, you can also go to Settings → System → Recovery (on Windows 10, Settings → Update & Security → Recovery), choose Restart now next to Advanced startup, then Use a device and pick the USB stick.

  3. Choose the USB stick from the menu. It may be listed by its brand name, and may appear twice; choose the entry that starts with UEFI.

  4. A menu appears with Try or install SakuraOS selected. Press Enter, or wait 15 seconds. Use the with screen reader entry if you need speech.

  5. After a minute or two the SakuraOS installer opens. Continue with Installing.

If the USB stick will not start

You get an error about Secure Boot, or it goes straight back to Windows

The SakuraOS USB stick does not start while Secure Boot is on. Turn it off in the firmware settings:

  1. Open the firmware settings. On most computers, press Del or F2 as it starts. From Windows: Settings → System → Recovery → Advanced startup → Restart now (on Windows 10, Update & Security → Recovery), then Troubleshoot → Advanced options → UEFI Firmware Settings.

  2. Find Secure Boot, usually under a Security or Boot tab, and set it to Disabled.

  3. Save and exit, usually with F10.

If you want to use Secure Boot with SakuraOS, there is a better option than turning it off. See Secure Boot before you change anything.

If Windows uses BitLocker or Device Encryption, changing Secure Boot makes Windows ask for its recovery key on the next start. Make sure you have the key first. See BitLocker.

The USB stick is not in the boot menu

  • Turn off Fast Boot in the firmware settings, which can skip USB devices.
  • Try another USB port, and avoid hubs and docks.
  • Write the image again. If you used Rufus, make sure you chose DD Image mode.

The screen stays black after choosing the stick

Wait two minutes; the first start can be slow on some machines. If it still shows nothing, the graphics card may need different settings. Ask in the community, and mention your graphics card.
