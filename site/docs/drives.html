Other drives and USB sticks

Drives other than the one SakuraOS is on, including USB sticks, external drives and a Windows partition, appear in the file manager, Dolphin.

Opening a drive

  1. Open Dolphin. Drives are listed in the sidebar under Devices.

  2. Click a drive to open it. For a drive inside the computer, you may be asked for your password.

  3. Before unplugging a USB stick or external drive, click the eject icon beside it and wait for it to disappear. Unplugging without doing this can lose files that were still being written.

SakuraOS reads and writes drives formatted for Windows (NTFS, exFAT and FAT32) as well as Linux file systems.

Opening a drive automatically

  1. Open System Settings and search for Auto-Mount. Open Device Auto-Mount.

  2. Find the drive under Attached Devices. It is listed only after you have opened it once in Dolphin.

  3. Tick On Login to open it every time you log in, and press Apply.

Formatting a drive

Install KDE Partition Manager, which can format, create and resize partitions. In a terminal: 

sudo pacman -S partitionmanager

Then open KDE Partition Manager from the application menu.

Formatting erases everything on the drive. Check the drive's name and size before you confirm, and never format the drive SakuraOS is on.

To use a USB stick with Windows and macOS as well, format it as exFAT.

What is using my space?

Open Filelight, which is installed, and choose a folder or drive. It shows what takes up the space as a chart you can click into. If the system drive is full, see The disk is full.
