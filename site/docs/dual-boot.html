Installing beside Windows

SakuraOS can share a computer with Windows. When the computer starts, a menu lets you choose which one to use. This page covers the preparation in Windows, the install, and the few things that behave differently afterwards.

Two ways to do it

  • Windows and SakuraOS on the same disk. You make room in Windows first, then install SakuraOS into that space. Follow this whole page.
  • SakuraOS on a separate disk. Simpler and safer if you have a second disk. In the installer, choose that disk and Erase the whole disk; the Windows disk is not touched. To choose between them afterwards, use the computer's boot menu key (see Making a USB). SakuraOS's own menu only lists systems on the same disk as SakuraOS.

Before you start

Back up anything important in Windows first. Resizing a partition is normally safe, but a power cut or a mistake during it can cost you your files.

Get your BitLocker recovery key

Many Windows computers encrypt their disk with BitLocker, also called Device Encryption. Changing firmware settings, including Secure Boot, can make Windows ask for its 48-digit recovery key on the next start. Without the key you cannot get into Windows.

If your Windows account is a Microsoft account, the key is usually saved at account.microsoft.com/devices/recoverykey. You can also save it from Windows: search the Start menu for Manage BitLocker and choose Back up your recovery key. Keep it somewhere other than this computer, such as printed out or on your phone.

Turn off Fast Startup

Fast Startup makes Windows hibernate instead of shutting down, which leaves its disk locked. Other systems, including SakuraOS, cannot then safely use it.

  1. Open Control Panel → Hardware and Sound → Power Options.

  2. Choose Choose what the power buttons do, then Change settings that are currently unavailable.

  3. Untick Turn on fast startup and save.

Make room for SakuraOS

SakuraOS needs at least 25 GB of unallocated space: space that no partition uses. 64 GB or more is better. Windows can shrink its own partition to make it:

  1. Right-click the Start button and choose Disk Management.

  2. Right-click the (C:) partition and choose Shrink Volume.

  3. Enter how much to free, in MB. For 64 GB, enter 65536. Choose Shrink.

  4. A new black bar labeled Unallocated appears. Leave it as it is: do not create a partition in it. SakuraOS installs there.

If Windows will not shrink as far as you want, it is usually because of files it cannot move. Freeing space on C: and running Disk Cleanup can help.

Install

  1. Start from the SakuraOS USB stick. See Making a USB. If the stick will not start because of Secure Boot, read the note there before turning Secure Boot off.

  2. Go through the installer as described in Installing.

  3. On the Disk screen, choose the disk that has Windows on it, then Install alongside what is here. It should say how much unallocated space it will use, and that it is keeping Windows.

    If the option is grayed out, the screen says why: either there is less than 25 GB unallocated, or nothing on the disk starts in UEFI mode.

  4. On the summary, check that it does not say the disk will be erased. Then install.

What the installer changes on the disk

  • It creates one new partition in the unallocated space. Your Windows partitions are not resized, moved or changed.
  • It shares Windows' existing EFI system partition, adding a folder named EFI/sakura. Windows' own boot files stay where they are.
  • It adds a startup entry named SakuraOS to the firmware, first in the order.
  • It also places its boot loader at the firmware's fallback location, EFI/BOOT/BOOTX64.EFI, which some computers use when their startup entries are lost. On a computer with Windows, this replaces Windows' copy at that location. Windows' main boot entry is not affected, and SakuraOS's menu still offers Windows.

Choosing a system when the computer starts

The SakuraOS menu shows for 3 seconds and then starts SakuraOS. To start Windows instead, press ↓ to stop the countdown, select Windows Boot Manager, and press Enter.

After installing

The computer starts straight into Windows

Large Windows updates sometimes put Windows first in the firmware's startup order again. Open the firmware settings, find the boot order, and move SakuraOS to the top. To start SakuraOS once without changing anything, use the boot menu key instead.

The clock in Windows is wrong by a few hours

Windows and SakuraOS store the time in the computer's clock differently: Windows as local time, SakuraOS as UTC. After using one, the other can be off by your time zone's difference from UTC. The simplest fix is to tell Windows to use UTC as well. In Windows, open Command Prompt as administrator and run: 

reg add "HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\TimeZoneInformation" /v RealTimeIsUniversal /d 1 /t REG_DWORD /f

Then restart Windows and let it set its clock from the internet once.

Opening your Windows files from SakuraOS

The Windows partition appears in the file manager's sidebar. Click it to open it, and type your password when asked. If Windows was not fully shut down, for example because Fast Startup is still on, it may open read-only or not at all. A Windows partition encrypted with BitLocker cannot be read without its recovery key.
