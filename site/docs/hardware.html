Hardware and drivers

Most hardware works with no setup: the installer chooses graphics drivers for you, and firmware for most Wi-Fi, Bluetooth and graphics chips is included. This page covers the exceptions.

Graphics

Intel and AMD graphics use the drivers built into Linux and need nothing installed.

NVIDIA

The installer picks a driver based on the card's age:

CardsDriver
GTX 16 series, RTX 20 series and newerNVIDIA's current driver
GTX 750, 900 series and 1000 seriesNVIDIA's 580 driver, the last one that supports these cards. SakuraOS packages it so they keep working.
Older cardsNouveau, the open-source driver. Fine for the desktop; slow for games.

The 580 driver is not on the USB stick, so it is downloaded during the install. If you install without an internet connection on one of these cards, you get Nouveau instead. To switch afterwards, connect to the internet and run: 

sudo pacman -S nvidia-580xx-dkms nvidia-580xx-utils linux-cachyos-headers

If uname -r does not end in cachyos, your computer uses the standard kernel: replace linux-cachyos-headers with linux-headers. Restart when it finishes.

Which driver am I using?

In a terminal:

lspci -k -d 10de:

The line Kernel driver in use says nvidia for NVIDIA's driver or nouveau for Nouveau.

Laptops with two graphics chips

Many laptops have Intel or AMD graphics for everyday use and an NVIDIA chip for heavier work. The desktop runs on the Intel or AMD chip.

On some of these laptops the installer does not yet recognize the NVIDIA chip and installs no NVIDIA driver. Check with lspci -k -d 10de:: if no Kernel driver in use line says nvidia, install the driver for your card from the table above. For an RTX or GTX 16 series chip: 

sudo pacman -S nvidia-open nvidia-utils

To run a game or program on the NVIDIA chip, start it with these settings. In Steam, put this line in the game's Properties → Launch Options: 

__NV_PRIME_RENDER_OFFLOAD=1 __VK_LAYER_NV_optimus=NVIDIA_only __GLX_VENDOR_LIBRARY_NAME=nvidia %command%

Wi-Fi and Bluetooth

Most Wi-Fi and Bluetooth hardware works as soon as SakuraOS starts. Connect from the network icon in the panel.

If Wi-Fi does not appear at all, see No Wi-Fi. Some older Broadcom chips need a separate driver: sudo pacman -S broadcom-wl-dkms, then restart.

Printers and scanners

Add a printer in System Settings → Printers. Drivers for most printers are included. HP printers often work better with HP's own driver: sudo pacman -S hplip.

Scanners work with Skanpage, which is installed.

Laptops

The battery icon in the panel switches between power modes: power saving, balanced and performance. Automatic updates wait until the laptop is plugged in.

Sleep and resume use Linux's standard support, and have not been tested on a wide range of laptops yet. If yours does not wake properly, please report it with the laptop's model.

Firmware updates

Many computers can update their own firmware from Linux through the Linux Vendor Firmware Service. SakuraOS does not include the tool for this; to use it: 

sudo pacman -S fwupd
fwupdmgr refresh
fwupdmgr get-updates
fwupdmgr update

Only update firmware while plugged in, and do not turn the computer off during an update.
