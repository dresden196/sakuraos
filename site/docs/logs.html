Logs and bug reports

A report with the right information attached can usually be answered in one reply. This page shows how to collect it.

Your hardware

inxi prints a summary of your hardware with serial numbers and network addresses removed. Install it once, then run it: 

sudo pacman -S inxi
inxi -Fxz

The system log

Most problems leave a message in the system log. Read it with journalctl: 

journalctl -b -p err      # errors since the computer started
journalctl -b -1 -p err   # errors from the previous start, after a crash
journalctl -b             # everything since the computer started
journalctl -f             # new messages as they happen, while you reproduce the problem

Inside the log, use the arrow keys and Page Up/Page Down to scroll, / to search, and q to quit. To save one to a file you can attach: 

journalctl -b -p err > ~/errors.txt

Hardware not detected

For a device that does not appear, or firmware that failed to load:

sudo dmesg -T | grep -iE 'firmware|error|fail'

What changed recently

The Update Center's History shows every change with its restore point. The same list as text: 

grep -E 'upgraded|installed|removed' /var/log/pacman.log | tail -40

SakuraOS's own parts

journalctl -u sakura-updates        # the nightly update
journalctl -u sakura-boot-success   # counting failed starts
journalctl -u sakura-kernel-sync    # setting up the kernel after going back

For a problem during installation, open Konsole in the live session before restarting and run journalctl -t sakura-install.

The recovery screen writes to the screen only. A photo of it is a perfectly good bug report.

A program that will not open

Start it from a terminal, where it prints why it stopped. For SakuraOS's applications the commands are sakura-store-ui for the App Store and sakura-update-center for the Update Center.

Before you share a log

Logs can contain your username, your computer's name, and the names of your Wi-Fi networks and files. Read through a log before posting it publicly, and remove anything you would rather not share.
