System requirements

SakuraOS runs on 64-bit PCs with UEFI firmware. Most computers sold since about 2012 qualify.

Processor

Any 64-bit Intel or AMD processor works. Processors that support a feature set called x86-64-v3 get a faster, tuned kernel. That covers most Intel processors from 2013 (Haswell) onward and AMD processors from 2015 (Excavator) onward; some low-cost Pentium and Celeron models lack it. Processors without it get the standard Arch Linux kernel instead. You do not choose; the installer checks for you. See Kernel.

32-bit processors and ARM computers, including Apple Silicon Macs and Raspberry Pis, are not supported.

Firmware

SakuraOS needs UEFI firmware. Nearly every PC sold with Windows 8 or later has it. On an older computer that only has a legacy BIOS, the USB stick will start, but the installed system will not.

Secure Boot does not need to be on. If you want it, see Secure Boot on the installing page.

Memory

A full install and the desktop have been tested with 2 GB. For everyday use with a web browser and a few programs open, 8 GB is comfortable. SakuraOS compresses memory before it runs out, which helps smaller machines. See compressed swap.

Storage

The installer needs at least 25 GB. More gives you room for restore points, which grow as you install updates and applications, so 64 GB or more is a better starting point. An SSD makes a large difference to how fast the system feels.

Graphics

Intel and AMD graphics work with no setup. NVIDIA cards work too, but which driver you get depends on the card's age, and older cards need an internet connection during the install. See NVIDIA before you install on an NVIDIA machine.

Internet

You can install without a connection: everything needed for a working desktop, including a web browser, is on the USB stick. Connect afterwards to get updates and install applications.

Virtual machines

SakuraOS is tested in QEMU/KVM virtual machines. In any virtual machine, choose UEFI (sometimes called EFI) firmware rather than BIOS, and give it at least 2 GB of memory and a 25 GB disk.

Not tested yet

Intel Macs have not been tested and may need extra drivers, particularly models with an Apple T2 chip. If you try SakuraOS on hardware that does not work, please report it.
